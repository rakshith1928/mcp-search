# Omnisearch v1.2 — Reliability & npm Publication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bound provider latency (timeouts), absorb transient failures (retries), gate merges with CI, escape provider titles in markdown, and prepare all four packages for npm publication.

**Architecture:** The router constructs a fresh `AbortSignal.timeout()` per attempt and passes it through `SearchOptions.signal` to every provider (fetch `signal` option; SDK per-call `{ signal }` request options). A retry wrapper inside the router's attempt loop (single + parallel paths) re-calls the same provider up to 2 extra times on transient failures only, re-acquiring its rate-limit token and sleeping exponential backoff + jitter (sleep injectable for tests). Escaping is a normalizer-local helper. CI is a two-OS GitHub Actions matrix.

**Tech Stack:** Bun + TypeScript (NodeNext), zod 4.1.8 pinned, @modelcontextprotocol/sdk, OpenAI/Anthropic SDKs (per-call `signal` support), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-02-v1.2-reliability-npm-design.md` (decisions in ADR-0001…0007)

## Global Constraints

- Fixed `MAX_RETRIES = 2` (3 attempts total) — **not** env-configurable (ADR-0004).
- Timeout default **30000 ms**, overridable only globally via `OMNISEARCH_TIMEOUT_MS` (positive integer, validated like other numeric env vars) (ADR-0003).
- Retries only on transient failures: HTTP 5xx/429, network errors, timeouts; permanent errors (other 4xx, config) fall through immediately (ADR-0004).
- Every retry re-acquires the provider's rate-limit token — no limiter bypass (ADR-0004).
- Escape `[ ] ( )` in titles only; URLs and snippets untouched (ADR-0007).
- Zero new runtime dependencies (ADR-0002).
- All existing tests must stay green; single-provider back-compat unchanged.
- Repo commands from root: `bun test`, `bun run typecheck`, `bun run build`. Relative imports use `.js` extensions.
- Version target: **0.3.0** everywhere (Task 6).

1. Constants and exports at module level:

```typescript
const MAX_RETRIES = 2;

/**
 * Transient failures get retried (ADR-0004): HTTP 5xx/429 (the standardized
 * provider message shape), network errors, and timeouts/aborts. Everything
 * else — auth, quota, config — is permanent and falls through immediately.
 */
export function isTransientSearchError(error: unknown): boolean {
  if (!(error instanceof Error)) return false;
  const message = error.message ?? "";
  if (/HTTP\s+(5\d\d|429)/.test(message)) return true;
  if (/aborted|timed?\s*out/i.test(message)) return true;
  if (/fetch failed/i.test(message)) return true;
  let cause: unknown = error.cause;
  while (cause instanceof Error) {
    if (/ECONNRESET|ETIMEDOUT|ECONNREFUSED|fetch failed/i.test(cause.message)) return true;
    cause = cause.cause;
  }
  return false;
}

function backoffMs(attempt: number, random: () => number = Math.random): number {
  const base = 500 * Math.pow(2, attempt - 1);
  return base + Math.floor(random() * 250);
}
```

4. Restructure the single-path attempt loop (replace the existing per-name body — provider resolution moves OUTSIDE the retry loop; limiter acquisition and a fresh signal happen per attempt):

```typescript
    for (const name of attemptChain) {
      try {
        const provider = await providerFor(name);
        for (let attempt = 1; attempt <= MAX_RETRIES + 1; attempt++) {
          try {
            await limiterFor(name)?.acquire();
            const signal = AbortSignal.timeout(config.timeoutMs ?? DEFAULT_TIMEOUT_MS);
            const results = await provider.search(query, { ...options, signal });
            const markdown = normalizeResults(query, name, results);
            const fellBack = name !== effectivePrimary;
            const value: CacheValue = {
              provider: name,
              requestedProvider: fellBack ? effectivePrimary : undefined,
              fellBack,
              results,
              markdown,
            };
            cache.set(key, value);
            return {
              query,
              provider: value.provider,
              requestedProvider: value.requestedProvider,
              fellBack: value.fellBack,
              results,
              markdown,
              cached: false,
              elapsedMs: Date.now() - startedAt,
            };
          } catch (error) {
            if (attempt <= MAX_RETRIES && isTransientSearchError(error)) {
              await sleepImpl(backoffMs(attempt));
              continue;
            }
            throw error;
          }
        }
        throw new Error(`${name}: exhausted retries`);
      } catch (error) {
        errors.push(`${name}: ${error instanceof Error ? error.message : String(error)}`);
      }
    }
```

5. Parallel task — same shape per participant:

```typescript
    const tasks = participants.map(async (name) => {
      const perKey = cacheKey(name, query, options);
      const perCached = cache.get(perKey);
      if (perCached && !perCached.fellBack && perCached.provider === name) return perCached.results;
      const provider = await providerFor(name);
      let lastError: unknown;
      for (let attempt = 1; attempt <= MAX_RETRIES + 1; attempt++) {
        try {

            requestedProvider: undefined,
            fellBack: false,
            results,
            markdown: normalizeResults(query, name, results),
          });
          return results;
        } catch (error) {
          lastError = error;
          if (attempt <= MAX_RETRIES && isTransientSearchError(error)) {
            await sleepImpl(backoffMs(attempt));
            continue;
          }
          throw error;
        }
      }
      throw lastError;
    });
```
