# omnisearch-kilocode

Multi-provider web search (8 providers) for Kilocode via the omnisearch
engine. Configure in kilo.jsonc:

    "plugin": [["omnisearch-kilocode", { "provider": "brave" }]]

Set provider keys as environment variables (e.g. BRAVE_API_KEY).
Repo and docs: https://github.com/<your-org>/omni-search#readme
