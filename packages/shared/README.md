# @omnisearch/shared

Platform-agnostic plugin logic for omnisearch: `createPluginHooks(options,
toolFn)` builds the search router and the `omnisearch` tool definition,
with the host platform's `tool()` helper injected. Consumed by
omnisearch-opencode and omnisearch-kilocode.

Repo and docs: https://github.com/<your-org>/omni-search#readme
