# omnisearch-opencode

Multi-provider web search (8 providers) for OpenCode via the omnisearch
engine. Configure in opencode.json:

    "plugin": [["omnisearch-opencode", { "provider": "brave" }]]

Set provider keys as environment variables (e.g. BRAVE_API_KEY).
Repo and docs: https://github.com/<your-org>/omni-search#readme
